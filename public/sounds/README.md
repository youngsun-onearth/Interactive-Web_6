# Sampler sounds

Place one sound per key in this folder using a lowercase filename:

- `q.wav` or `q.mp3`
- `w.wav` or `w.mp3`
- `e.wav` or `e.mp3`
- `a.wav` or `a.mp3`
- `s.wav` or `s.mp3`
- `d.wav` or `d.mp3`
- `z.wav` or `z.mp3`
- `x.wav` or `x.mp3`
- `c.wav` or `c.mp3`

When both formats exist for the same key, the sampler loads the WAV file first.
