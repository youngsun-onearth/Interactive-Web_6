# DoodleFace 단일 생성 프롬프트

아래 코드 블록 전체를 Codex에 한 번만 입력합니다.

```text
현재 열려 있는 웹 프로젝트를 먼저 충분히 분석한 뒤, 기존 예제·스타일·라우팅·빌드를 깨뜨리지 않고 로컬 2인 카메라 게임 예제 “DoodleFace”를 실제로 완성해줘. 설계만 설명하지 말고 코드, 스타일, 테스트와 문서를 수정하고 빌드 및 브라우저 테스트까지 실행해줘.

요구사항:
- 기존 상단 예제 메뉴에 DoodleFace 버튼을 추가한다. 현재 DoodleFace 디자인이 있다면 배경, 타이포그래피, HUD, 2분할 패널, 팔레트, 알림과 그래픽을 유지한다.
- 네트워크, 방 서버, WebRTC, WebSocket, SSE와 관련 환경변수는 사용하지 않는다. 한 PC·한 브라우저·한 카메라 앞에 두 사람이 나란히 플레이한다.
- 로비에는 `2인 게임 시작 ＋`와 `게임 방법 ?` 버튼을 표시한다. 시작하면 audio:false/facingMode:user 카메라를 한 번만 열고, 원본을 정확히 좌우 절반으로 잘라 각 canvas에 cover·거울 모드로 그린다.
- FaceLandmarker 1개는 numFaces:2, HandLandmarker 1개는 numHands:2로 설정한다. `public/mediapipe`의 로컬 모델/WASM을 사용하고 GPU 실패 시 CPU로 재시도한다.
- 거울 좌표의 얼굴·손 중심이 x<0.5면 PLAYER 1, 아니면 PLAYER 2에 고정 배정한다. 얼굴과 손 좌표는 각각 자기 화면 절반의 0..1 로컬 좌표로 변환한다.
- 얼굴이 없어도 카메라는 계속 보여야 한다. 미인식 상태는 카메라를 가리지 않는 작은 반투명 WAITING 배지로 표시한다. 좌우 얼굴이 각각 약 650ms 안정적으로 감지되면 5초 카운트다운을 시작한다.
- 카운트다운이 끝나면 현재 좌우 카메라 프레임을 전환 레이어에 복사하고, 두 화면이 약 850ms 동안 반대편으로 미끄러져 이동하는 애니메이션으로 교환한다. 데스크톱은 수평, 세로형 모바일 레이아웃은 수직으로 이동하며 순간 전환이나 단순 페이드는 사용하지 않는다. 애니메이션이 끝난 뒤부터 정확히 60초를 센다.
- 교환 후 왼쪽 패널에는 PLAYER 2, 오른쪽 패널에는 PLAYER 1 얼굴이 보인다. PLAYER 1의 손은 왼쪽 상대 화면, PLAYER 2의 손은 오른쪽 상대 화면의 펜을 조작한다.
- 펜은 알아보기 쉬운 큰 연필 모양으로 그리고 펜촉과 실제 선 좌표를 정확히 일치시킨다. 각 패널 상단에 동일한 10색 팔레트를 두며 색 위에서 Pinch하거나 클릭하면 해당 플레이어 색만 바뀐다.
- 펜 위치는 엄지·검지 끝의 중간이다. 엄지-검지 거리/손바닥 폭 비율에 히스테리시스를 적용하고, Pinch 시작 임계값은 넉넉하게, 해제는 약 110ms 안정화 후 확정하며, 손이 잠깐 사라지면 약 220ms 동안 마지막 펜·Pinch를 유지해 획이 끊기지 않게 한다.
- Pinch 시작점이 상대 얼굴 안일 때만 새 획을 만든다. 얼굴 안에서 시작한 획은 Pinch를 놓을 때까지 얼굴 밖에서도 이어진다. 점마다 대상 얼굴의 가장 가까운 랜드마크와 얼굴 크기·회전 기준 오프셋을 저장해 이동·확대·회전·표정을 따라가게 한다.
- 새 점은 같은 추론 프레임에 즉시 보인다. 얼굴 추론 사이에는 직전 두 포즈로 짧게 예측해 낙서 지연을 줄인다. Pinch 중에는 손 추론을 조금 더 자주 배정하되 프레임당 추론은 하나만 수행한다. 저사양 기기는 카메라 fps, 추론 해상도, canvas DPR과 렌더 빈도를 낮춘다. 낙서 점마다 getBoundingClientRect를 호출하지 말고 패널 변환값을 프레임당 한 번만 계산한다.
- 60초가 끝나면 작은 `완성된 얼굴을 보여주세요` 안내를 약 2.4초 표시한 뒤 숨기고, 교환된 결과 화면을 약 10초 더 보여준 다음 카메라와 MediaPipe 자원을 정리하고 로비로 돌아간다.
- 카메라 거절, 비보안 컨텍스트, 모델 오류는 짧은 한국어 메시지로 알리고 재시도 가능하게 한다. 예제를 떠날 때 카메라 트랙, 추론 객체, requestAnimationFrame과 상태를 모두 정리한다.

검증:
- TypeScript/Vite 빌드를 통과시킨다.
- 가짜 단일 카메라와 얼굴 478점 2세트, 손 21점 2세트로 자동 테스트한다.
- 메뉴 진입, 얼굴별 WAITING, 대기 중 카메라 노출, 자동 카운트다운, 실제 이동 전환 애니메이션, 60초 타이머, 양쪽 Pinch 즉시 드로잉, 일시적 손 누락에도 이어지는 획, 얼굴 밖 연장과 얼굴 추적, 2.4초 안내, 10초 결과 감상, 로비 복귀를 검증한다.
- 가능하면 Chromium, Firefox, WebKit과 모바일 뷰포트에서 테스트한다.

완료 후 변경 파일과 테스트 결과만 간결하게 보고해줘.
```
